# Правила создания карточек (для Claude)

Этот файл — инструкция для Claude. Женя присылает слова (иногда с примером, где он их встретил), Claude возвращает **JSON-файл по [IMPORT_FORMAT.md](IMPORT_FORMAT.md)**, Женя отправляет его боту.

Основа — алгоритм, по которому Женя раньше делал карточки, плюс правила интервального повторения (атомарность, без перегруза).

## 1. Антиповтор

- Перед генерацией сверить новый список с текущей колодой. Источник — свежий `/export` из бота или список `externalId`, если Женя его прислал.
- Слово, выражение или конструкция уже есть в колоде → **не добавлять**. Если новое значение действительно другое, это отдельная запись с суффиксом (`de:bank-2`) и подсказкой `hint`.
- Внутри одной порции дублей тоже нет.

## 2. Грамматическая обвязка

**Существительные**
- `article` обязателен, `lemma` без артикля.
- `plural` с артиклем: `die Weggänge`. Если множественного числа нет — `nur Sg.`

**Глаголы**
- `praeteritum`, `perfekt` с hat/ist: `geriet`, `ist geraten`.
- **du-форма** только там, где меняется корневая гласная или есть неправильность: `note: "du gerätst"`, `"du hältst fest"`.
- Жёсткое управление (предлог + падеж) — в `rektion`: `auf + Akk.` (verzichten auf).
- Возвратность входит в `lemma`: `sich kümmern`.

**Прилагательные и наречия**: только перевод и пример, без лишнего.

## 3. Пример (контекст)

- Если Женя прислал свой пример, берём его. Можно слегка поправить грамматику. Перевод на русский точный по смыслу, не дословный.
- Если примера нет, Claude пишет живую фразу из реальности Жени:
  - фронтенд-разработка, React/TS, код-ревью, дейли, разговор с тимлидом или заказчиком, архитектура;
  - быт и официальные дела в Германии: договоры, налоги, врачи, авто, Jobcenter, банк, Kita.
- **Никаких учебниковых штампов** («Der Hund ist braun»).
- Одно предложение уровня B2–C1, до ~15 слов. Слово в примере в той же форме или естественной грамматической форме.
- Пример устарел, неестественный или в нём ошибка → переписать.

## 4. Атомарность (из практики Anki/SuperMemo)

- **Одно значение на запись.** У многозначного слова отдельные записи, у каждой свой `hint`.
- Перевод короткий: 1–3 синонима через запятую. Длинные пояснения уходят в `note`.
- Не перегружать `translation` артиклем, множественным числом и формами: для них есть свои поля, бот покажет их сам.
- Ложные друзья → `falseFriend`.
- Регистр: `umgs` (разговорное) / `formell` (официальное). Нейтральное не помечаем.

## 4a. Уроки первой проверки лингвистом

- В примере стоит **сама лемма**, а не составное слово (не Putenbrust, а Pute). Первым идёт основное значение, переносное — отдельной записью с суффиксом `-2`.
- `hint` обязателен, если у русского перевода есть сильный немецкий «конкурент»: подход → Ansatz, неудача → Misserfolg, поступать → handeln. Особенно для субстантивированных инфинитивов (das Vorgehen, das Scheitern, das Auftreten). Уточнение не дублировать в `translation` и `hint`.
- Регистр пишется **только в поле `register`**, не в `note` и не в `tags`. Амтсдойч (Arbeitsaufnahme, unverzüglich, Einwände erheben) всегда `formell`.
- Никаких шаблонов из писем («Zögern Sie nicht…»). Примеры — конкретные сцены из дейли, ревью, деплоя и быта.
- Факты в примерах должны быть правдой для Германии (цены, обычаи, законы).

## 5. externalId и теги

- `externalId`: `de:` + lemma в нижнем регистре, пробелы → `-`: `de:sich-kümmern`, `de:gerät`. **Никогда не меняется**, даже если поменялся перевод.
- `tags`: тема (`it`, `office`, `behörde`, `alltag`, `arzt`, `auto`) + часть речи. Не больше 4.

## 6. Проверка независимым лингвистом (обязательно)

Перед тем как отдать файл Жене, Claude запускает **отдельного агента-лингвиста** (C2-германист, не видевший генерацию). Он проверяет каждую запись: грамматику, естественность примера, точность перевода, атомарность, hint и register. Claude вносит правки и только потом отдаёт файл, с короткой сводкой «что поправил лингвист».

## 7. Формат ответа Claude

1. Короткая сводка: сколько слов пришло, сколько отсеяно как дубли (и какие именно), что поправлено.
2. Файл `.json` (schemaVersion 1, `deck.key: "de"`, если Женя не сказал другое).
3. Ничего не выдумывать: если слово непонятно или похоже на опечатку, спросить.

## 8. Для вопросов к собеседованию (`basic`)

- Один вопрос из Interview Pack превращается в 3–6 маленьких карточек, а не одну огромную.
- Ответ должен проговариваться вслух за 15 секунд, иначе карточку надо дробить.
- Follow-ups `вопрос :: ответ` становятся отдельными карточками один к одному.
- Код на лицевой стороне только в формате «что выведет?», 3–6 строк.
- Теги: `interview`, тема, `MUST`/`SHOULD`.
