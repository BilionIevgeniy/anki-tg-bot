# Как пользоваться ботом

## Каждый день

| Что | Как |
|---|---|
| Учить всё, что ждёт | `/learn` |
| Посмотреть, что на сегодня | `/today` |
| Остановиться | кнопка ⏹ Стоп (ничего не теряется) |

Карточка → вспоминаешь → **👁 Показать ответ** → честно оцениваешь:

- ❌ **Снова** — не вспомнил (вернётся через минуту)
- 😐 **Трудно** — вспомнил с трудом
- ✅ **Хорошо** — нормально вспомнил, это основная кнопка
- 🚀 **Легко** — знаю отлично

На кнопках написано, через сколько карточка вернётся. Ошибся кнопкой → **↩️ Отменить ответ** под следующей карточкой.

Из каждого немецкого слова получаются 2–3 карточки: DE→RU, RU→DE и, для существительных, «Какой артикль?» с кнопками der/die/das (проверяется автоматически). Карточки одного слова в один день не показываются.

## Добавить новые слова

Открыть **новый чат с Claude** (подключён репозиторий `anki-tg-bot`) и написать:

> Создай и добавь карты: Gerät, sich kümmern um, die Abrechnung, … (можно с примерами, где встретил)

Claude:
1. сверит слова с уже имеющимися и выкинет дубли;
2. сделает карточки по правилам (формы, управление, живой пример из IT или жизни в Германии);
3. отдаст их на проверку независимому лингвисту и поправит;
4. запушит в репозиторий.

Через ~3 минуты Render передеплоит бота, и он пришлёт в Telegram: **«📥 Колоды обновлены…»**. Всё, можно учить.

Продолжить чистку старой колоды из Noji: **«давай следующую пачку из Noji»**.

## Настройки

| Команда | Что делает |
|---|---|
| `/decks` | колоды: лимит новых в день (±5), пауза, экспорт |
| `/notify` | напоминание для каждой колоды: время, «если ждут ≥ N», вкл/выкл |
| `/stats` | статистика: сколько в долгой памяти, % вспоминания |
| `/leeches` | «пиявки» — слова с 8 ошибками, бот их отложил; лучше попросить Claude переформулировать |
| `/timezone Europe/Berlin` | часовой пояс; новый день начинается в 4:00 |
| `/export` | бэкап колод с прогрессом (JSON) |
| `/import` | загрузить JSON вручную, если нужно без репозитория |

## Если что-то сломалось

- Бот не отвечает → Render → сервис `anki-tg-bot` → **Logs**. Скрин последних строк — в чат Claude.
- Напоминания не приходят → UptimeRobot: монитор `/jobs/tick?secret=…` должен быть зелёным.
- Карточки после пуша не появились → в логах Render искать `deck sync:`; ошибки файла видны там же и в Telegram.

## Инфраструктура (всё бесплатно)

- **Render** — сервер бота (автодеплой из `main`)
- **Neon** — база PostgreSQL (проект `anki-tg-bot`, Frankfurt, 0.25 CU)
- **UptimeRobot** — `/health` каждые 5 мин (чтобы не засыпал) и `/jobs/tick?secret=JOBS_SECRET` каждые 15 мин (напоминания)
- **Telegram** — бот через @BotFather

Переменные окружения в Render: `BOT_TOKEN`, `DATABASE_URL`, `ALLOWED_TELEGRAM_IDS` (твой ID), `BOT_MODE=webhook`. `WEBHOOK_SECRET` и `JOBS_SECRET` генерирует Render. Адрес сервиса берётся автоматически.
