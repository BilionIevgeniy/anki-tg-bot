Правила чистки:
1. Дубли одного слова в одном значении → ОДНА запись. Лучший пример выбери (или улучши), исправь ошибки.
2. Разные значения/слова → разные записи (атомарность). Многозначность — суффиксы externalId (-1, -2) и обязательный hint.
3. fields: lemma (БЕЗ артикля), article (для существительных), plural ("die Geräte" или "nur Sg."), pos (noun/verb/adj/adv/phrase/other), translation (1–3 синонима), hint (если у перевода есть немецкий «конкурент»), praeteritum + perfekt (с hat/ist) для глаголов, note (du-форма ТОЛЬКО при смене корневой гласной/неправильности, предупреждения), rektion ("auf + Akk."), register (umgs/formell — только в этом поле), example (одно живое предложение B2–C1 с САМОЙ леммой, не составным словом), exampleTranslation (точный естественный русский), falseFriend (если есть).
4. Проверяй факты: формы, род, множественное, hat/ist, управление. Исправляй ошибки Noji (неверные формы, корявые/неграмматичные/устаревшие примеры, факты, неверные для Германии).
5. externalId: "de:" + lemma в нижнем регистре, пробелы → "-", умлауты оставь (de:gerät, de:sich-kümmern, de:umgehen-mit). Субстантивированные инфинитивы при наличии одноимённого глагола: "de:das-vorgehen". Значения: de:erheben-1 / de:erheben-2. Фразы: короткий слаг (de:voreilige-entscheidung-treffen). Разрешены только буквы, цифры и _ : . - /
6. tags: первым всегда "noji", потом тема (it, office, behörde, alltag, bewerbung, auto, arzt, geld, essen…) и часть речи; максимум 4.
7. "_src" (перенос прогресса изучения): у записи основного значения группы — ключ группы ровно как во входном файле. Если в группе смешаны существительное и глагол и у обоих есть изученные карточки — используй "<ключ>#noun" и "<ключ>#verb". Отделённое дополнительное значение/новое слово без своей изученной карточки — "__none__". Каждая группа входа должна оказаться либо в _src хотя бы одной записи, либо в _dropped.
8. _dropped — только для мусора (пустые/непонятные/опечатки без смысла) или групп, которые полностью дублируют другую группу ЭТОЙ ЖЕ пачки (тогда reason: "дубль группы X"). Не выбрасывай нормальные слова.
9. Не выдумывай: если слово действительно непонятно — в _dropped с reason, но старайся восстановить по смыслу.
